# UniPedia sitemap

The browsable sitemap is available at `/sitemap`. The generated search-engine sitemap is `/sitemap.xml`, generated by `npm run build` through `scripts/generate-sitemap.mjs`.

## Site structure

```text
Home /
├── UGC pathway
│   ├── Profile /courses
│   ├── Results /courses?view=results
│   ├── Browse without a profile /explore
│   ├── Programme details /courses/:uniCode — 255 offerings
│   └── UGC institution directory /institutions
│       └── Institution profiles /universities/:code — 20 institutions
├── Private & other study routes
│   ├── Programme directory /pathways
│   ├── Programme details /programmes/:id — 130 programmes
│   └── Institution directory /institutions?route=catalogue
│       └── Institution profiles /institutions/:slug — 13 institutions
├── Student guides /guides
│   ├── /guides/understanding-z-scores
│   ├── /guides/degree-or-hnd
│   ├── /guides/foundation-routes
│   └── /guides/planning-study-costs
├── Student tools /tools
│   ├── Study budget /tools/budget
│   ├── UGC academic checks /courses?view=profile#academic-requirements
│   ├── Saved choices /shortlist
│   ├── UGC comparison /compare
│   ├── Other-programme comparison /compare?route=catalogue
│   ├── Interests /interests
│   └── Dates & official notices /dates
└── About & help
    ├── Sources and methodology /about
    ├── Feedback & corrections /contact
    ├── Privacy /privacy
    ├── Terms /terms
    └── Sitemap /sitemap
```

## Search-engine coverage

The XML sitemap contains **438 unique public URLs**: 255 UGC programme pages, 130 other-programme pages, 33 institution profiles, four guide articles and 16 directory/tool/information destinations.

Personal shortlist and comparison pages are omitted from XML and have client-side `noindex`. Filter, pagination and finder-step query variants are omitted. The other-institution directory has its own canonical route query because it represents a separate admission route. No speculative `lastmod` dates are supplied.

The browsable sitemap includes personal planning destinations for navigation and collapsible complete programme indexes. Website, programme, saved-state and admission data are unchanged by sitemap generation.
